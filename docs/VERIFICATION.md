The nine `Cipher_Photos` portraits were decoded, EXIF-oriented and converted to WebP with smaller variants. The live database contains five published reference leaders and four unpublished profiles awaiting role confirmation. The Team page screenshot was inspected; desktop/mobile browser tests verified image loading. Original source photos, Git HEAD, LICENSE and README were preserved. An earlier production-build attempt was blocked by a temporary automatic-review usage limit; the subsequent reviewed build succeeded.

The site has not been publicly deployed. Hosting account setup, HTTPS, persistent MongoDB and upload storage, backups, and final submission remain with the team. SMTP settings are now present; real delivery was not exercised in this update. Tests use a fake transport. Normal tab-close logout uses a 30-second grace period; browser crashes may skip its signal and rely on session-cookie/15-minute server expiry instead. No Lighthouse score or real-device test is claimed.
